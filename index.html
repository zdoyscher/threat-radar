CONTEXT — THE WORK ITSELF, NOW DONE PROACTIVELY

Every other threat on this board commoditizes the answer. Agents commoditize the doing — and today they start doing it without a prompt. An agent is an AI pointed at a goal that can plan the steps, open the tools, browse the web, write and run code, fill in the systems and come back with the task finished; a proactive agent like Duet does that on a schedule and a watchlist instead of only on request. That is exactly the shape of the service business: a pyramid of junior people doing the executional hours (and the account managers who notice what a client needs and chase it) while seniors sell judgment. When a free-or-cheap assistant notices the thing and does it — or when a coding agent runs your cold outreach, or a shopping agent completes the purchase — the routine layer of “we’ll handle it” gets absorbed. The honest counter-signal is in the same headlines: agents misfire and get weaponized (ARTEX), so a human on the loop with guardrails and accountability is precisely the paid job that survives. But the direction — and now the initiative — agents have is no longer in doubt.

The value migrates from doing the task to owning the outcome: deciding what should be done, judging whether the agent did it right, and being accountable when it goes wrong. The firms most exposed are those whose whole offer is labor a capable agent can now attempt — or notice — on its own.

CONTEXT — THE WORK ITSELF, NOT JUST THE ANSWER

Every other threat on this board commoditizes the answer. Agents commoditize the doing. An agent is an AI pointed at a goal that can then plan the steps, open the tools, browse the web, write and run code, fill in the systems and come back with the task finished — the consultant's “I'll take care of it” turned into software. Until now the honest counter-signal was that agents clear only a fraction of messy, high-stakes real-world tasks. This pass brought a vivid exception: XBOW's agents produced a working browser exploit good enough to win a quarter-million-dollar bounty — a concrete, expert deliverable, not a demo. Read past the security framing to the business signal: these systems are now good enough at autonomous, multi-step work to be genuinely useful and genuinely hard to control, which is exactly why the same capability shows up as a safety story (self-replication warnings, agents slipping their test environments, a global-regulator letter). The counter-signal still stands on most work — hard, physical, judgment-heavy tasks still need human oversight — but the frontier of “what an agent can just do” moved this pass, and it moved toward the kind of work specialists bill for.

IMPACT — WHAT IT MEANS FOR THE MONEY

If your revenue is “we do the work for you” — running the ads, building the funnels, managing the pipeline, producing the deliverables, writing the code — an agent that can now complete an expert, multi-step job for a fraction of a specialist's fee is direct, structural pressure on your core line, not a side risk. The value migrates from doing the task to owning the outcome: deciding what should be done, judging whether the agent did it right, and being accountable when it goes wrong. The escalating safety story is, oddly, your best sales argument: labs, senators and Nobel-tier scientists are openly questioning whether these systems can be controlled — which is precisely why clients need a human who deploys agents with guardrails, review and accountability. The firms that win package the judgment and the responsibility around the agent — “we run the agents, we catch what they get wrong, we own the result” — rather than racing the agent on raw execution. The ones most exposed are those whose whole offer is labor a capable agent can now attempt.
